# ✨ Scripts — Personal Toolbox

A small, opinionated collection of handy scripts for any purpose: quick automations, developer helpers, and one-off utilities.

- **Purpose:** Keep reusable, minimal scripts you can inspect and run quickly.
- **Usage:** Read the top-of-file usage notes, then run with the appropriate interpreter (e.g., `bash`, `python`). Prefer `--help` when available.
- **Safety:** Always review a script before executing. Do not run untrusted scripts with elevated privileges.
- **Contributing:** Add a clearly named script file, include a short header (purpose, usage, examples), and open a PR.
- **License:** This is a personal collection. Add a `LICENSE` if you want to publish with a specific license.

Enjoy — use responsibly and iterate often. 🚀
